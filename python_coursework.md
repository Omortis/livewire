# Python Homework Course

## Problem Statement

We need to create some homework exercises covering the following topics in Python:

1. NumPy
2. Pandas
3. Matplotlib
4. Object oriented concepts

## Guidelines

- These exercises should target someone who is already generally proficient in Python.
- Perhaps 5-10 exercises for each topic.
- Problems should be drawn from the realm of power system simulation methodologies such as load flow analysis, contingency analysis, and production cost modeling if possible though this is not strictly necessary.
- Difficulty should ramp up progressively within each topic. Exercises should be practical and reflect day-to-day analysis tasks at a power engineering firm.
- A mix of general data analysis and power systems specific problems is encouraged.

## Document Format

The output should be a Markdown file generated in the local directory.
